### Hi, I'm Kacper 👋

Principal Engineer and Open Source Tech Lead at [Vstorm](https://vstorm.co). I build production AI agents in Python, mostly in the [Pydantic AI](https://ai.pydantic.dev) ecosystem, and I write about what breaks on the way.

**What I'm building now**

- [**AgenticOS**](https://github.com/vstorm-co/agenticos): an open-source (Apache-2.0), self-hosted platform where a company builds, shares and governs its AI agents. Budgets are checked before every model request, sensitive tools wait for a person, and every run is recorded. Built on Pydantic AI and [pydantic-ai-harness](https://github.com/pydantic/pydantic-ai-harness).
- Upstream work on [pydantic-ai-harness](https://github.com/pydantic/pydantic-ai-harness/pulls?q=is%3Apr+author%3ADEENUU1+is%3Amerged) (memory, planning, spend limits, tool guards, compaction) and [Pydantic AI](https://github.com/pydantic/pydantic-ai/pulls?q=is%3Apr+author%3ADEENUU1+is%3Amerged).
